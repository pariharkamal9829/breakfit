# BreakFit — Premium Dry Fruits E-Commerce Website

A Shopify-style multi-page e-commerce website for premium dry fruits and nuts.

## Features

- 🛒 Full shopping cart with localStorage persistence
- 📦 6 pages: Home, Shop, Product Detail, Cart, Checkout, About
- 🎨 Shopify-quality UI with warm earthy color palette
- 📱 Mobile-first responsive design with hamburger nav
- ✨ Smooth animations (hero slider, scroll pop-ins, toast notifications)
- 💬 WhatsApp floating chat button
- ⭐ Product reviews & star ratings
- 🔍 Filter & sort by category, price, rating
- 💳 3-step checkout with form validation
- 🚀 Zero dependencies — deploys to Netlify instantly

## Pages

## Deploy to Netlify

1. Connect this repo to [Netlify](https://netlify.com)
2. Set **Publish directory** to `.` (root)
3. No build command needed
4. Deploy!

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (ES5 compatible)
- Google Fonts (Playfair Display + Inter)
- Remix Icons CDN
- No build tools, no npm, no framework
